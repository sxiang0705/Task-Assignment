# 遺忘曲線大禮包 必上岸版本 — 個人完整版 — 2026-09-14

此包包含執行所需的 EXE 與相依檔案，不需自行安裝 Python。這是本機驗收版，不是已通過全部發布門檻的正式版。

## 開始使用

1. 將 ZIP 完整解壓縮至新的資料夾，不要直接在 ZIP 裡啟動。
2. 保留「遺忘曲線大禮包 必上岸版本.exe」與 _internal 資料夾的相對位置，不要只複製 EXE。
3. 啟動「遺忘曲線大禮包 必上岸版本.exe」，首頁應為「今日任務」。
4. 舊版程式請先關閉。一般模式沿用本機的既有資料，解壓縮至新資料夾不代表資料隔離。

一般模式的資料位於 `%LOCALAPPDATA%\TaskAssignment\`。程式更新前建議先建立 ZIP 備份。請勿把備份或驗收時的匯入當成合併資料；匯入會完整取代目前資料。

## 建議先在隔離資料中驗收

在解壓縮後的 TaskAssignment 資料夾開啟 PowerShell，執行：

```powershell
$env:TASK_ASSIGNMENT_DATA_DIR = Join-Path $env:TEMP ('TaskAssignment-Acceptance-' + [guid]::NewGuid().ToString('N'))
.\遺忘曲線大禮包 必上岸版本.exe
```

這會建立獨立的空白驗收資料，不修改正式資料；測試資料保留在該暫存路徑。驗收完畢後關閉此 PowerShell 視窗，以免後續沿用隔離設定。

## 本版驗收標準與重點

本輪針對使用者回報修改：月曆選日直接更新清單；表單內可新增分類／標籤，標籤有用途說明；自訂排程改為日期時間選擇器，僅在選到自訂模式時顯示；一般視窗的預覽固定在右側，小視窗保留必要捲動。分類／標籤建立後即成為共用選項，不因取消任務刪除。

優先檢查月曆換日期是否即時、建立分類是否直覺、自訂日期加入／移除／防重複，以及 3～10 次複習的增加／減少按鈕在邊界是否清楚停用。本輪新增任務版型已變更，請重新確認這個表單。

啟動上限 10 秒、一般查詢／篩選／定位／切頁 1 秒，大量儀表板沿用 2 秒。長時間備份／匯入要求有狀態回饋、介面可回應及清楚結果，不要求在 1 秒完成。5 秒啟動與 300ms 查詢僅為後續優化目標。

上一版已確認的其他頁面不必全部重測；確認能啟動、沿用資料正常，以及本機備份結束後按鈕恢復可用即可。

現有自動化已涵蓋備份還原跨程序重啟及背景工作接續；150%／200% 目前僅通過離屏控制項邊界測試，該環境無可用字型，因此不能視為實機文字顯示通過。
